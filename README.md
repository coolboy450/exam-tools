# เครื่องมือเตรียมสอบเข้า · Exam-prep tools

เครื่องมือฟรีสำหรับนักเรียนเตรียมสอบเข้า ม.1 / ม.4 ทำงานบนเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์ ไม่ส่งข้อมูลไปไหน
Free browser tools for Thai entrance-exam prep. No server, nothing leaves your device.

👉 **[ลองใช้ / Live](https://coolboy450.github.io/exam-tools/)**

## มีอะไร
- 🎯 **คำนวณคะแนน** ใส่คะแนนและน้ำหนักแต่ละวิชา ดูว่าถึงเป้าไหม และวิชาที่ยังไม่สอบต้องได้เฉลี่ยเท่าไหร่ (ไม่มีข้อมูลคะแนนขั้นต่ำของโรงเรียน ใส่เกณฑ์เองตามที่โรงเรียนประกาศ)
- 📅 **ตารางอ่านหนังสือ** ใส่วันสอบ ชั่วโมงที่อ่านได้ และความมั่นใจแต่ละวิชา ได้ตารางรายสัปดาห์ที่พิมพ์ได้ วิชาที่อ่อนได้เวลามากกว่า

## English
- **Score calculator**: weighted total vs. your target, plus the average you still need on the subjects you haven't taken. Bring your own school criteria.
- **Study planner**: exam date + hours per day + confidence per subject → a printable weekly timetable.

ใช้คู่กับ [ติวกับนูบ](https://github.com/coolboy450/tiwkapnoob) (ข้อสอบฝึกทำ) และ [exam-practice-template](https://github.com/coolboy450/exam-practice-template) (ทำเว็บฝึกข้อสอบของตัวเอง)

เปิดในเครื่อง: `py -3 -m http.server` แล้วเข้า http://localhost:8000 · Run locally with any static server.
